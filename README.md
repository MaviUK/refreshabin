# ordered.food

A UK food-ordering marketplace built as a monorepo for customer, restaurant and admin products.

## Workspace

- `apps/customer` — customer web/PWA
- `apps/restaurant` — restaurant Android app
- `apps/admin` — platform administration
- `packages/ui` — shared design system
- `packages/types` — shared TypeScript contracts
- `packages/api` — shared API clients
- `supabase` — database migrations and backend configuration

## Brand

- Pink: `#FF78AC`
- Teal: `#A8D5E3`
- Cream: `#F2F0EA`

## First product milestone

A restaurant owner can sign up, create a restaurant, configure opening hours and build a menu.
